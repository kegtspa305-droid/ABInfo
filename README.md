# ABInfo — متجر إلكتروني

نسخة مطورة من ABInfo بواجهة عربية/فرنسية/إنجليزية، وضع نهاري/ليلي، منتجات وطلبات وعملاء، والدفع عند الاستلام فقط.

## لا يوجد مخزون
هذا المشروع لا يحتوي على إدارة مخزون أو أرصدة أو حركات مستودع. الكمية في السلة هي كمية الطلب فقط.

## تشغيل محلي
1. ثبّت Node.js LTS.
2. داخل المجلد نفّذ `npm install`.
3. انسخ `.env.example` إلى `.env` واضبط `SESSION_SECRET`.
4. نفّذ `npm start`.
5. افتح `http://localhost:3000`.

حساب الإدارة الأولي:
- username: `admin`
- password: `admin123`

غيّر كلمة المرور فورًا من لوحة الإدارة.

## التوصيل
تم إنشاء جدول مستقل لكل ولاية. أسعار التوصيل الافتراضية = 0 DZD حتى تدخل الأسعار الحقيقية من لوحة الإدارة.

## الولايات
تم تجهيز 69 ولاية وفق التقسيم الإداري المستهدف حاليًا؛ وزارة الداخلية أوضحت أن الولايات الإحدى عشرة الجديدة يبدأ أداء صلاحياتها كاملة من 1 يناير 2027 ضمن الإطار الانتقالي، لذلك يمكن تعديل القائمة/التفعيل من الكود عند تغير الوضع القانوني.

## Google Sheets / Forms / Apps Script
مجلد `google-apps-script` يحتوي على `Code.gs` و`appsscript.json`.
1. افتح Google Apps Script بحساب المتجر.
2. أنشئ مشروعًا والصق Code.gs.
3. شغّل `setup()` مرة واحدة وامنح الصلاحيات.
4. ضع `SCRIPT_SECRET` في Script Properties.
5. Deploy > New deployment > Web app، واختر التشغيل بحسابك والإتاحة المناسبة لك.
6. ضع رابط Web App في `GOOGLE_APPS_SCRIPT_URL` على الخادم، والسر نفسه في `GOOGLE_APPS_SCRIPT_SECRET`.
7. لا تضع السر في JavaScript المتصفح.

المعرفات الحالية في المشروع مأخوذة من بيانات ABInfo التي زوّد بها صاحب المشروع:
- Sheet: `11PqHIHH_uydQ40GF6RpkeohWBCj0P8Bjnx-2XnK4VsA`
- Form: `1MeXGHFoIhgA8ToVTtrL3OFgtecZiM1IV7zw-QrPMiRU`

## النشر وHTTPS
المشروع يعمل على Node.js. في الاستضافة التي توفر HTTPS أمام التطبيق، شغّل Node على PORT داخلي مثل 3000 واترك مزود الاستضافة/Reverse Proxy يدير HTTPS.

إذا كانت الاستضافة تسمح لـ Node بإدارة HTTPS مباشرة، يمكن ضبط `SSL_CERT_PATH` و`SSL_KEY_PATH`.

## النطاق
الهدف: `www.abinfo.dz`.
تسجيل نطاق `.dz` يتم عبر إجراءات NIC-DZ/مسجل معتمد، ويجب أن يملك مقدم الطلب حقًا مثبتًا في الاسم وفق ميثاق NIC-DZ.

## قبل الإطلاق
- إدخال المنتجات الحقيقية والصور.
- إدخال أسعار التوصيل الـ69 من لوحة الإدارة.
- تغيير كلمة مرور admin.
- تغيير SESSION_SECRET.
- إضافة سياسة الخصوصية والشروط والاسترجاع وبيانات التوصيل.
- اختبار الطلب من الهاتف والكمبيوتر.
- ربط Google Apps Script واختبار تسجيل طلب في Sheets.
- شراء/تسجيل النطاق والاستضافة ثم توجيه DNS إلى الاستضافة.

## نشر مجاني مقترح
ملف `render.yaml` و`DEPLOY_RENDER.md` مجهزان للنشر على Render Free. Render يدعم Node.js/Express ويمنح الخدمة عنوان `onrender.com` وTLS تلقائيًا. لا تعتمد على SQLite وحدها كقاعدة بيانات دائمة في الخطة المجانية؛ استخدم Google Sheets/Apps Script للتخزين المتزامن قبل الإطلاق التجاري.
